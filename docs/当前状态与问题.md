## 未解决问题

| 问题 | 影响 | 处理方向 |
| --- | --- | --- |
| 业务值随模型诊断重复保存 | 数据库里保留模型响应和输入摘要，含业务值副本 | 对外部署前决定是否脱敏或缩短保留期 |
| 后台失败消息带内部文件位置 | 客户端能看到代码文件名和行号 | 对外部署前统一处理所有输出路径 |
| 启动校验不核对生成列表达式 | 旧库可能仍在用旧的唯一键表达式 | 结构变更后按 `backend/resource/schema.sql` 重建 |
| 复杂规则库第二轮可能超时 | 历史记录显示财报类规则库较慢，近期未复验 | 用真实大规则库重跑确认 |
| PaddleOCR 供应商 500 根因未知 | 只能按失败、续查或重试处理 | 需要供应商侧证据 |
| CSV 崩溃恢复有限 | 进程被强杀、断电、磁盘故障可能留下不完整文件 | 依赖备份和人工恢复 |
| 模型偶发返回非法工具参数 | `LLM_TOOL_ARGUMENTS_INVALID` 会让所在批次字段记为未执行 | 频繁出现时增加把错误回给模型的重试 |
| 编制跨样本质量与速度 | 合同样本118条及原编号来源已核对，首轮约10分钟；无编号、自定义表头和更大文件仍缺证据 | 扩展不同布局样本；按原文语义、资料完整性和真实业务问题评估，不把结构通过当全文正确 |
| 导入内容职责识别未验证 | 两轮契约、资料留存和页面已修改，尚无真实模型结果证明分类准确 | 对照原文核对误造规则、漏掉真实要求、重复定义及辅助资料归属；不以结构通过代替语义正确 |
| 材料质量前置未运行验证 | 时机识别、逐文件模型结论、处理停止及续跑缺运行证据 | 使用同任务一份不合格与一份合格文件，核对工具参数来自已发布规则、不合格文件未调用处理服务、合格文件继续；覆盖缺阈值、工具失败、续跑、字段确认、换版和重试 |
| 编制与后续场景解析未衔接验收 | 首轮、单句修改、只解释、Excel 已验证，导出后再解析为场景配置未运行 | 用最终导出进入原解析工作台核对；不据编制验收认定执行配置或审核结果正确 |
