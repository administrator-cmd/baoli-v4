# 报告模板

报告管理中的「报告模板」用于提炼已完成报告的章节结构与表达风格。第一版只影响报告正文的章节组织、语气、详略和标题/列表表达；任务配置的报告章节、规则结果与字段事实仍是业务内容的唯一来源，模板里的具体客户、金额、日期和结论不会复制到新报告。

用户可上传 PDF。所有 PDF 均直接交由项目现有 PaddleOCR 在线作业客户端识别，使用 `.env` 中的 `BAOLI_OCR_SERVICE_URL`、`BAOLI_OCR_TOKEN`、`BAOLI_OCR_MODEL` 提交与轮询；不使用本地 PDF 解析库或 PaddleOCR 模型。提取的报告样本文字只在分析请求期间使用，不保存到数据库；原 PDF 保存在 `data/report_templates/<template_no>/source.pdf`。模型输出按 `ReportStyleProfile` 校验后保存到 `report_template.style_profile_json`，档案版本当前为 `1.0`，页面支持查看与编辑 JSON，也可重新分析。

模板列表提供原始 PDF 预览入口；预览通过只读内联响应读取服务端保存的原件，不重传文件、不触发 OCR 或模型分析。

档案必须包含非空的报告概述及至少一个名称非空的章节，空对象、空章节列表和纯空白内容不能作为成功结果保存。整份档案按报告提示词的 JSON 格式序列化后，UTF-8 编码不超过 8 KiB（8192 字节），其中嵌套的结构/表达字典也计入预算；每条格式说明最多 500 字符。模型分析、手工保存、创建任务及报告执行使用相同的档案有效性标准；前三处严格拒绝无效档案，执行历史任务时仅对 `REPORT_TEMPLATE_PROFILE_INVALID` 降级，跳过风格注入并继续按真实规则与数据生成报告，其他错误仍正常抛出。

报告生成时在既有 `snapshot_json.report_generation` 中保存实际 `mode`、原选 `requested_mode`、模板身份及降级原因。任务报告面板与报告管理详情读取已保存的元数据，明确显示「模板档案无效，本次按规则生成」和原选模板名称。风格降级不加入业务缺项，也不改变审核范围完整性或风险可判定信号。不修改任务冻结档案，不改用模板当前版本；历史报告缺少这类元数据时不补造。此前因该档案错误阻断的任务允许原批次继续执行，其他配置和数据错误不因此放开续跑。

列表与详情按模板隔离无效档案：该条响应不返回风格 JSON，并提供不可用原因；其他模板照常展示。读取不改写数据库原档案，无效档案不能出现在任务选择项中。没有可用档案的模板也可以单独修改名称；更新请求省略 `style_profile` 或传 `null` 仅修改名称，保留原档案、状态和分析错误，不清空档案。

上传只负责保存原件和受理风格分析，OCR 与模型调用在持久化后台操作中执行，页面凭操作状态查询真实进度；客户端超时或离开页面不触发第二次分析，刷新后也会从模板列表接续查询。每个模板同一时间只允许一个活跃分析操作，编辑档案与分析互斥。

上传幂等重放只比较原文件名、字节数和 SHA-256，不依赖可修改的模板名称。模板改名后重放原上传请求仍返回原记录及原分析操作，不覆盖新名称；同一幂等键用于不同文件仍返回冲突。

重新分析失败时只保存错误说明，保留已有风格档案；若 OCR 已完成，页数按本轮识别更新，OCR 未完成则保留原页数。已有档案仍可用于创建任务，任务创建时继续冻结其副本。首次分析失败则模板没有风格档案，显示失败并可重新分析。后台操作状态使用既有 `background_operation` 表，不新增报告模板数据表。服务中断留下的操作会按全局后台操作约定标为中断，刷新后可看到中断状态并重新发起分析。

创建审核任务时可选择「按规则生成」或「仿照模板」。模板档案在任务创建时复制进冻结的 `manifest_json.report_generation`，所以之后编辑模板不会改变已创建任务。报告执行提示会把档案作为风格参考传给模型，并明确禁止将其作为事实或规则。Markdown 仍是现有报告输出格式；PDF/Word 等模板版式复刻尚未实现。

数据库新增 `report_template` 表，迁移为 `0008_report_templates`；上传请求幂等键由 `0009_report_template_upload_key` 增加。本次只增加迁移文件与空库完整 schema，不执行数据库迁移。

验证范围：43 项报告模板后端回归、9 项规则执行回归、12 项字段核对/续跑回归、4 项 OCR 生命周期回归，以及 17 项前端回归通过，前端类型检查与定向代码检查通过。OCR 生命周期测试已对接模块化后的执行入口，仍验证失败终态先提交、网络超时保留原作业、失败作业不自动重提和 READY 不联系供应商。数据库、OCR 和模型均使用替身；未执行真实接口调用、数据库迁移、构建或浏览器验收。
