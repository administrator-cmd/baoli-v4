# baoli-v4 前端产品与交互规范

更新：2026-09-15。性质：长期前端契约。

前端是面向重复业务操作的 Element Plus 管理后台。页面应安静、紧凑、可扫描，优先表格、表单和明确操作，不使用营销首页、装饰性大卡片或长篇功能说明。当前实现差距见 [当前状态与问题台账.md](当前状态与问题台账.md)。

## 1. 对象关系

用户看到五类核心对象：

| 对象 | 用户任务 |
| --- | --- |
| 审核场景 | 维护材料、字段、规则、风险和报告配置，发布版本 |
| 场景版本 | 查看不可变配置、比较版本、创建修订 |
| 审核方案 | 从一个固定场景版本选择审核范围，发布方案版本 |
| 方案版本 | 查看冻结范围，并据此创建审核任务 |
| 审核任务 | 上传材料、执行节点、复核、查看风险和报告 |

关系是：场景 -> 场景版本 -> 方案版本 -> 审核任务。页面必须显示当前对象和版本，不能把草稿、已发布版本和任务快照混在同一可编辑状态中。

## 2. 信息架构

默认首页是审核任务列表。侧边栏固定六组菜单：

| 分组 | 页面 |
| --- | --- |
| 场景管理 | 场景列表、材料配置、字段配置、规则配置、规则库导入、场景版本 |
| 方案管理 | 方案列表、方案版本 |
| 审核管理 | 审核任务、人工复核、执行记录 |
| 资料管理 | 审核材料、证据记录 |
| 报告管理 | 审核报告、风险结果 |
| 系统管理 | 服务状态、操作日志 |

列表页进入访问页签；详情和编辑页保持所属菜单高亮，不为每个对象详情无限新增页签。面包屑、页签和浏览器返回都要保留对象身份。旧链接重定向时必须保留原任务号或导入作业号，不能跳到列表中的另一条记录。

## 3. 页面骨架

- 使用 Vue 3、TypeScript、Vue Router、Element Plus 和已有图标库，不引入第二套组件库。
- 侧边栏、顶栏、访问页签和内容区保持稳定尺寸；内容区优先利用横向空间。
- 列表首屏依次为查询条件、工具栏、表格和分页，不重复显示眉题、大标题和说明卡。
- 常规文字 14px，区块标题 16px；不随视口缩放字号，不使用负字距。
- 表格使用边框和斑马纹，操作列固定在右侧；金额右对齐，状态、方向和关键结果不能只放在 hover 中。
- 普通弹窗约 600px，复杂弹窗约 800px；复杂规则和方案使用独立编辑页。
- 卡片只用于独立重复项、弹窗或确实需要边界的工具，不把页面分区全部做成浮动卡片。

页面内容必须在 1920、1440、1024 和窄屏下不重叠。窄屏优先重排导航、查询条件和表单；表格允许受控横向滚动，不靠缩小字号塞入。

## 4. 列表与 CRUD

查询、排序、分页、总数和导出使用同一个后端作用域。查询和重置回到第一页；切换查询条件后清理过期选择。当前页全选不自动扩大为全库选择。

新增、编辑、删除、恢复、复制、启停和发布必须等待真实服务端结果后再更新页面。失败保留用户输入并显示真实错误；不能先改本地数组制造成功。批量操作发生部分失败时逐项显示原因。

业务对象默认逻辑删除，历史版本、任务、材料、事实、证据和报告不可级联抹除。场景或方案停用后不能用于新任务，已创建任务继续使用原快照。

删除材料或字段前显示具体引用；不能静默换用同名对象、自动删依赖规则或自动停用问题。草稿修改不影响已发布版本；已发布配置只读，修改必须先创建修订。

加载中使用当前表格或表单的 loading。无数据、筛选无匹配、读取失败和权限/服务错误是不同状态：

- 无数据：简短空状态和合法的新建入口；
- 无匹配：保留查询条件并允许重置；
- 读取失败：显示错误和重试；
- 字段无值：显示“—”，不能默认显示 0；
- 未知状态：写“状态未确认”，不能伪装为空数据。

## 5. 场景与规则库

场景列表提供新增、编辑基本资料、复制、启停、逻辑删除/恢复、配置、版本和创建方案。场景详情按基本信息、材料、字段、规则、报告和版本组织。

材料配置必须把两个字段分开：

- 材料名称：业务材料位名称，可由用户维护；
- 材料类型：8018 接受的 `doc_type`，使用后端取得的真实支持目录下拉，不能自由输入。

类型目录加载失败时显示外部服务错误并保留已有值，不内置或猜测候选，不把材料名称复制成材料类型。已保存但不在当前目录中的值显示为“当前目录不支持”，由用户明确修订。

字段配置按场景版本和材料筛选，显示名称、所属材料、类型、单位、币种、是否必抽、产物来源和提取要求。内部 key 可以在诊断详情显示，不能成为普通用户必须填写的字段。

规则配置使用业务名称和受支持的选项。用户选择材料、字段、检查方式、参数、风险和状态；前端不要求填写 Python 算子名、JSON 或工具 ID。选项来自后端统一能力注册表，不能维护一份独立静态枚举。

规则库导入首页是作业列表，新增导入后进入详情。详情依次展示文件与 profile、Sheet/列识别、逐行结果和问题、发布预览、发布结果。每个错误可定位到真实 Sheet、行、列和原值。

上传组件从后端读取规则库大小限制。预览范围应明确标成“预览”，不能说超出范围的业务行不会解析。导入成功、结构有效、可以发布和真实审核正确必须使用不同状态表达。

## 6. 方案

方案列表提供新增、编辑草稿、复制、启停、删除/恢复、发布、版本和创建任务。方案编辑先选择一个明确场景版本，再选择业务规则；系统自动加入的依赖必须显示来源原因。

草稿不用于创建任务。发布后冻结场景版本、显式选择、自动依赖和有效范围。切换场景版本时展示引用变化并创建新修订，不能自动升级旧方案或旧任务。

## 7. 审核任务

任务列表显示编号、名称、场景、方案版本、当前节点、状态和创建时间。创建任务必须选择已发布且启用的方案版本，并在提交前显示真实材料位和审核范围摘要。

任务详情以材料、字段结果、规则结果、人工复核、风险、报告和执行记录为页签。流程进度用紧凑步骤条或节点表，不为每个节点放一张说明卡。

材料页按真实材料位上传。上传、首次补传、替换和移除当前文件都明确提示会产生输入修订和使哪些结果失效；历史文件可查看和下载。业务材料上传上限来自后端配置，不能复用规则库常量。

字段表同时显示系统原值、当前有效值、状态、证据和纠错入口。值 `0`、`false` 和空字符串按数据类型区分。规则表同时显示系统判断、人工处理和当前结论。

主操作由后端状态决定：可执行时显示“执行当前节点”，等待复核时显示“提交复核”，运行中显示进度和原操作查询。前端不能根据文案猜状态，也不能在响应未知时重复提交。

## 8. 人工复核与证据

人工复核先处理字段事实，再由系统重算依赖规则，随后处理新的规则待办。复核表单显示对象、系统原判断、原值、证据、人工决定、有效值、依据类型和理由。

保存草稿与提交结论是两个动作。草稿绑定任务输入修订和待办版本；页面刷新后应能恢复。版本过期时明确拒绝并展示新待办，不能自动把旧决定套到新文件。

证据抽屉必须提供对应原文件或真实处理产物入口，显示材料位、文件版本、页码/文本和定位状态。没有可靠坐标时不画假高亮；证据读取失败与没有证据分开显示。磁盘绝对路径、密钥和供应商签名地址不出现在页面。

印章主体候选显示双方原文、材料、文件版本和相似度，但相似度不能渲染成自动结论。用户明确选择一致、不一致或证据不足后才能提交。

## 9. 风险、报告和系统状态

风险列表只把确定异常计为命中；无法判断、不适用、未执行和待复核分别显示。没有风险记录、没有命中和“合同无风险”不是同一结论。

报告详情分别显示：文件是否生成、审核范围是否完整、风险是否可判断。正文只读，备注可编辑；重新生成产生新快照。只展示后端真实支持的下载格式，不能用 Markdown 改扩展名冒充 PDF、Word 或 Excel。

服务状态区分未配置、已配置未验证、可用、不可用和状态未知。配置存在不等于连接成功。操作日志记录真实写操作和后台命令；没有身份体系时不伪造用户名。

## 10. 异步、错误与可访问性

请求发送、服务端受理、后台执行、查询失败、终态已知和页面同步完成是不同阶段。收到 `202` 只表示已受理；轮询失败只说明当前状态未知。页面应继续查询原操作，不自动重发业务命令。

切换场景、方案或任务时清理旧对象的轮询、操作号、错误、草稿和响应。异步响应必须核对对象 ID 和请求代次，不能串到新页面。

错误靠近对应字段或操作区域；同一错误不同时弹 toast 和多张 alert。业务不合格、技术失败、证据不足、不适用、未启用和待复核使用不同文字和状态颜色。

菜单、查询、表格选择、分页、弹窗、证据抽屉和主要命令支持键盘；所有控件有可见焦点和可读名称。图标按钮使用已有 Lucide 图标并提供 tooltip。颜色不是传达状态的唯一方式，长文本可换行且不得遮挡相邻内容。
