# 导入与发布校验清点（2026-10-10）

本文对应当前 rule_library_v1 源码，不沿用旧九阶段编译清单。只做静态核对，未运行验收。

| 环节 | 保留的核对 | 不再阻断的业务限制 |
| --- | --- | --- |
| 模型返回 | 可读取 JSON、对象形状、真实来源和内部身份；单项失败留原因，其余导入 | 固定 Sheet、固定节点、固定算子、业务合理性、阈值或口径确认 |
| 草稿编译与发布 | 实际选入规则库工作表、对象唯一内部身份、原始定义可组织 | 九阶段 DAG、预置依赖、必需人工复核节点、材料/规则数量、报告名称与章节顺序、报告范围与格式、风险等级顺序 |
| 停用项 | 保存原文与内部身份供查看 | 算子、参数、业务内容和依赖检查 |
| 单条执行 | 实际输入引用、真实工具参数、结果结构与产出身份、可存储类型 | 程序对模型业务结论的再判定；一条不能执行导致整批拒收 |
| 报告保存 | 实际正文、实际格式、未执行项与失败原因 | 发布时提前判断报告业务要求是否完整 |
| 版本与事实 | 任务冻结范围、工具实现版本、真实上传身份、人工确认值不被覆盖 | 旧执行器兼容或自动转换 |

旧 MANIFEST_REPORT_* 分组校验、MANIFEST_NO_MATERIAL、MANIFEST_NO_RULE、MANIFEST_REVIEW_*、MANIFEST_NODE_SEQUENCE_CONFLICT 编译入口已移除。执行器不再通过固定能力类型选 handler。比较与文件处理等能力仍可作为真实工具函数使用，工具参数 Schema 不等于业务规则合理性检查。

引用无法定位、格式无法产出、模型或工具失败等由单条真实结果说明；未知程序异常继续暴露。未增加默认业务值、模拟成功路径或自动业务降级。

## 旧计算与裁决协议清理

不兼容旧业务裁决记录，不提供数据迁移。导入裁决 DTO、API、目标映射、属性白名单、别名合并、作答暂存、图等待/恢复和前端入口均已删除；场景编辑与方案启停仍通过当前配置接口进行。

删除旧 calculation 编译包、分档校验入口及专用 LLM 计算工具。计算定义不再要求固定引擎、CHECK/VALUE_ONLY 或 JudgementBand；formula 保存计算方法，requirement 保存完整业务要求，business_context 按实际原文标签保留补充信息，来源单元格完整保存。LLM 根据原文执行计算或判断，真实中间值用 COMPUTED 表达。

移除按关键词预判不支持、单位口径预审及旧导入发布接口。任务冻结版本和启用范围仍有效。旧裁决列已从实体、建表 SQL 和启动检查删除，导入不再写入裁决或伪装为裁决的流程元数据；恢复由 checkpoint 保存。本轮没有连接或修改实际数据库。

## 节点、字段与工具目录收尾

场景节点 CRUD、节点选表拒绝接口、孤儿节点面板与死表达式解析器均已删除。来源节点分类、人工复核参数、发布能力缺口确认、未配置检查类别与旧材料状态映射不再进入契约或页面。复核只由当前执行结果的实际要求触发。

工具目录统一在 domain/tool_catalog.py，旧 capabilities.py 及其节点约束、执行分发、参数清单和规则能力预判视图删除。/system/tools 直接返回工具定义；operators/registry.py 保留实际算子实现。任务仍冻结工具实现版本与规则启用范围，这用于真实执行对账，不兼容旧业务流程。

结果读取同步移除旧阶段依赖：跨任务风险列表按当前有效批次的真实风险结果读取；材料识别展示读取当前上传的识别产物。字段取数启用范围来自生效规则输出，不要求 LLM_EXTRACT 算子。前端字段编辑不再提交节点归属。
