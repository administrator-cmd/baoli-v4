# 业务逻辑

系统将业务维护的 Excel 规则库转为场景配置，对真实材料逐条审核，并保留结论、实际比较过程和原文证据；无法判定时明确说明原因。

## 对象与流程

| 对象 | 含义 |
| --- | --- |
| 场景 | 专家维护的材料、字段、规则、节点、风险和报告配置 |
| 场景版本 | 完整配置保存后自动生成的不可变配置 |
| 方案 | 业务用户基于某个场景版本作个性化调整，可继续编辑 |
| 任务 | 创建时冻结方案完整执行配置，用于审核一批真实材料 |

管理员在场景列表创建、查找和启停场景，在规则库导入模块上传 Excel、确认 Sheet 与节点绑定，在场景配置模块调整材料、字段、规则、流程和报告。配置完整时保存或确认导入会自动生成生效版本；不完整时显示未生效原因，旧版本保持可用。业务用户从生效场景生成方案，调整后创建任务，上传材料、执行并查看结果。新版本不会改写已有方案和任务。

同一场景重新导入会替换当前配置中的业务内容和 Sheet 绑定；确认前展示替换范围并核对修订，冲突时要求重新核对。

## 审核结论

结论链条为：审核事项、标准、原文、标准化事实、实际比较、结论及原因。原文与标准化值分别保存；页码和坐标只表示定位精度，不替代内容依据。人工纠正后保留系统原判断及来源。缺事实、证据、业务口径或执行能力时不默认通过。

计算只使用结构化字段、上游计算结果和明确常量，采用 Decimal；RAG 用于查找候选原文和证据，不参与数值计算。印章主体相似度只用于候选排序，主体是否一致由工作人员确认。

系统支持合同审核与财报分析共用一份模板协议；财报真实业务规则仍需依据真实样本和业务决定核对，当前完成情况见[状态台账](当前状态与问题台账.md)。
